010515 00001 ~ 09999 线圈 Coil Q 区 读写 00001 = Q0.0   00009 = Q1.0
Qb.n → Addr = 00001 + b×8 + n
02 10001 ~ 19999 离散输入 DI I 区 只读 10001 = I0.0   10009 = I1.0
Ib.n → Addr = 10001 + b×8 + n
04 30001 ~ 39999 输入寄存器 IR AIW 区 只读 30001 = AIW0   30002 = AIW2
AIWn → Addr = 30001 + n/2  (n 必须偶数)
030616 40001 ~ 49999 保持寄存器 HR V 区 读写 40001 = VW(HoldStart)   40002 = VW(HoldStart+2)
VWn → Addr = 40001 + (n − HoldStart)/2
※ HoldStart 为从站 MBUS_INIT 中配置的 V 区起始字节偏移，默认 = 0（即 40001 → VW0）。
