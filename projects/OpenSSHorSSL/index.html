🔑 SSH 密钥自动配置工具

一键在 Linux 服务器上生成 SSH 密钥对并完成安全配置

Debian/Ubuntu CentOS/RHEL Alpine Arch RSA 4096 RSA 8192 Ed25519

🚀 一键执行

在 Linux 服务器终端中粘贴以下命令：

命令行一键执行
bash <(curl -s https://raw.githubusercontent.com/ATX8T/ATX8T.github.io/main/projects/OpenSSHorSSL/ssh_admin_toolkit.sh)

国内加速：把 raw.githubusercontent.com 替换为 Gitee 镜像源，或使用 直链转换工具

⚙️ 功能

项目说明
发行版Debian/Ubuntu · CentOS/RHEL · Alpine · Arch
算法RSA 4096 · RSA 8192 · Ed25519
配置PubkeyAuthentication yes · PasswordAuthentication no · 自动备份

📋 执行流程

  1. 检测发行版 → 安装 OpenSSH
  2. 选择密钥算法（RSA 4096 / RSA 8192 / Ed25519）
  3. 生成密钥 → 配置 sshd_config（备份至 /etc/ssh/backup/）
  4. 可选显示私钥内容，复制到本地

🔌 连接服务器

生成后将私钥复制到本地 Windows，然后：

ssh -i "C:\Users\用户名\.ssh\id_rsa" root@服务器IP
文件作用处理
id_rsa私钥下载到本地，妥善保管
id_rsa.pub公钥留在服务器，无需下载

⚠️ 安全警告

⚠ 请注意以下安全事项：
• 需要 root 权限执行
• 执行后请删除服务器上的私钥
• 建议配合防火墙限制来源 IP
• 执行前确认服务器能连接 GitHub：ping raw.githubusercontent.com

📖 在线脚本链接组合方法

在浏览器中打开脚本文件时，地址栏显示的是 页面链接（带 GitHub 网页外壳），不能直接用于 curl。需要将其转换为 原始文件直链。

GitHub 转换规则

页面链接：
https://github.com/ATX8T/ATX8T.github.io/blob/main/...ssh_admin_toolkit.sh

转换为直链：
① 把 github.com → raw.githubusercontent.com
② 删除 /blob

https://raw.githubusercontent.com/ATX8T/ATX8T.github.io/main/...ssh_admin_toolkit.sh

Gitee 转换规则（国内更快）

https://gitee.com/.../blob/main/... → https://gitee.com/.../raw/main/...
把 /blob 替换为 /raw
链接类型返回内容能否 curl
github.com/.../blob/...HTML 网页❌ 不能
raw.githubusercontent.com/...纯文本✅ 可以
gitee.com/.../blob/...HTML 网页❌ 不能
gitee.com/.../raw/...纯文本✅ 可以
