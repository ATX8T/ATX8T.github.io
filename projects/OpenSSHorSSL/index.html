🔑 SSH 密钥自动配置工具

一键在 Linux 服务器上生成 SSH 密钥对并完成安全配置。支持 Debian/Ubuntu、CentOS/RHEL、Alpine、Arch 等主流发行版。

v3.0 Apache 2.0 需 root 权限

🚀 一键执行

在服务器上运行以下命令（需要 root 权限）：

curl -sSL https://raw.githubusercontent.com/ATX8T/ATX8T.github.io/main/projects/OpenSSHorSSL/ssh_admin_toolkit.sh | bash复制

⚠️ 脚本会自动检测发行版、安装 OpenSSH、生成密钥、配置 sshd_config

🔐 支持的密钥算法

RSA 4096
经典算法，兼容性最佳
RSA 8192
RSA 增强版，更高安全性
Ed25519
现代椭圆曲线，快速安全

📋 执行流程

1
检测 Linux 发行版 → 自动安装 openssh-client / openssh-server
2
交互选择密钥算法 (RSA 4096 / RSA 8192 / Ed25519)
3
生成密钥对 → 配置 /etc/ssh/sshd_config
4
可选显示私钥内容，复制到本地即可 SSH 登录

⚙️ 自动配置项

PubkeyAuthentication yes
PasswordAuthentication no
PermitRootLogin yes
AuthorizedKeysFile .ssh/authorized_keys
X11Forwarding no
IgnoreRhosts yes
