# 简化部署
```
安装 Hexo
npm install -g hexo-cli


安装 Hexo 完成后，请执行下列命令，Hexo 将会在指定文件夹中新建所需要的文件。
hexo init <folder>
cd <folder>
npm install

例如
hexo init niubi
cd niubi
npm install

关键文件
_config.yml  
网站的 配置 文件。 您可以在此配置大部分的参数。
package.json  
应用程序的信息。 EJS, Stylus 和 Markdown 渲染引擎 已默认安装，您可以自由移除。 如果您想可以稍后卸载它们。


生成静态文件
hexo generate  # 简写：hexo g

# 启动本地服务，默认端口 4000
hexo server  # 简写：hexo s

# 清空 public 目录和缓存
hexo clean  


组合命令-----重启服务生效
hexo clean && hexo g && hexo s

```

## 部署到 GitHub Pages
```
需要先安装部署插件
npm install hexo-deployer-git --save

本地已安装 Git 并配置好 GitHub 账号（关联用户名和邮箱）例如：

git config --global user.name "你的GitHub用户名"
git config --global user.email "你的GitHub邮箱@xxx.com"


git config --global user.name "ATX8T"
git config --global user.email "gyt56863696@193.com


修改_config.yml 文件

原来样子
# Deployment
## Docs: https://hexo.io/docs/one-command-deployment
deploy:
  type: ''



修改后

# Deployment
## Docs: https://hexo.io/docs/one-command-deployment
deploy:
  type: git
  repo: https://github.com/ATX8T/Hexo.git
  branch: main  # 或 master（根据你的仓库默认分支调整）
  message: "Site updated: {{ now('YYYY-MM-DD HH:mm:ss') }}"  # 可选：部署提交的备注信息


执行部署
hexo deploy  # 简写：c

hexo clean && hexo g && hexo d


```

## 在 Hexo 中配置多个 GitHub 账户，并且能在部署（推送）时灵活切换不同账户对应的仓库
- Hexo 部署本质是调用 Git 推送，所以需要解决两个核心问题：
  - Git 层面：让不同仓库使用不同的 SSH/HTTPS 凭据（区分账户）；
  - Hexo 层面：配置多套部署规则，推送时指定用哪一套。
```
# 删除全局账户
git config --global --unset user.name
git config --global --unset user.email

# 删除当前仓库的账户
git config --local --unset user.name
git config --local --unset user.email

```
