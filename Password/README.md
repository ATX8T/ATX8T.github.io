# 随机密码生成器

> 生成高强度随机密码的在线工具

🔗 **在线预览**: [https://atx8t.github.io/Password/index.html](https://atx8t.github.io/Password/index.html)

---

## 功能特性

- 自定义密码长度（4-32位）
- 支持大小写字母、数字、符号
- 无重复字符设计
- 加密安全的随机数生成
- 历史记录保存（本地存储）
- 自动生成模式

## 技术实现

- 纯原生 JavaScript 实现
- 使用 `crypto.getRandomValues()` 加密安全随机数
- LocalStorage 存储历史记录
- 响应式设计，支持移动端
