📖 使用说明
📦 GitHub Raw 直链

格式: https://raw.githubusercontent.com/{owner}/{repo}/{branch}/{path}

✅ 优点: GitHub 官方，无需第三方
⚠️ 缺点: 国内访问可能较慢

🚀 jsDelivr CDN（推荐）

格式: https://cdn.jsdelivr.net/gh/{owner}/{repo}@{branch}/{path}

✅ 优点: 全球 CDN 加速，国内访问快，免费
⚠️ 缺点: 有缓存，更新非即时

📌 图床使用流程
  1. 打开 GitHub 仓库 → images 文件夹
  2. 点击 Add file → Upload files 上传图片
  3. 上传后在图片页面复制浏览器地址栏的 URL
  4. 粘贴到上方输入框 → 自动转换为可外链的图床地址
