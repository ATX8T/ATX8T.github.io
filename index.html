📖 使用说明
1️⃣
获取链接

在任意 GitHub 公开仓库中打开文件页面，复制浏览器地址栏的完整 URL

2️⃣
粘贴转换

粘贴到上方输入框，自动转为可直接访问的直链地址（支持 Raw / jsDelivr / Staticaly）

3️⃣
嵌入使用

复制 Raw 或 jsDelivr 链接，直接放入 <img src="..."> 或 Markdown 即可显示

类型URL 格式适用场景
Raw 直链 https://raw.githubusercontent.com/<owner>/<repo>/<branch>/<path> 直接下载、<img> 嵌入、浏览器打开
jsDelivr https://cdn.jsdelivr.net/gh/<owner>/<repo>@<branch>/<path> 国内 CDN 加速、生产环境推荐
Staticaly https://cdn.staticaly.com/gh/<owner>/<repo>/<branch>/<path> 备用 CDN 加速
